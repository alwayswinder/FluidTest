# 用户偏好（FluidTest 项目）

以下为该用户在 FluidTest 项目中的持久化偏好，执行相关操作时必须遵守：

## Git 提交

- **提交信息使用中文**：所有 git commit 的提交信息（commit message）必须使用中文撰写。
- 提交信息应简明扼要地描述本次改动的目的和内容。
- **只有用户主动要求时才执行提交和推送**：未经用户明确指示，不得擅自执行 git commit 或 git push。用户会说"提交"、"提交并推送"、"commit"、"push"等明确指令时方可操作。

## 代码与注释

- **代码注释使用中文**：编写的代码注释（包括行注释、块注释、文档注释）使用中文。
- 代码标识符（变量名、函数名、类名等）仍遵循项目既有命名规范（通常为英文），仅注释和文档使用中文。

## 交流

- 与用户交流时默认使用中文。

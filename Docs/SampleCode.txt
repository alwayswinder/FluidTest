重要补充说明：

所有 Map_Find 操作均从 MyRenderTargetsMap 中按字符串键查找对应的 TextureRenderTarget2D 对象。

所有布尔值转浮点数均使用 (float)bool（1.0 或 0.0）。

材质数组 MyCoreSimMaterials 的具体索引和用途已在伪代码中注明，索引从 0 开始。

MyFlipRenderTargetsForMobile 用于选择不同的材质索引，可能对应不同平台或渲染路径。

参数 Direction 在 PressureCycle1 中为 0.0，在 PressureCycle2 中为 1.0，体现交替迭代。

参数 KernelIndexOffset 使用 MyExperimentalPSolver2KernelIndexOffset，可能控制压力求解器内核偏移。

参数 DisablePressureEdgeMasking 根据 MyPressureEdgeMasking 是否为 0 来决定是否禁用边缘掩码。

MyPressureEdgeMasking 本身被钳制至少为 0.01（通过 FMax）。

参数 TexelSizeMult 根据 MyHalfResPressureAndDivergenceBuffers 决定是 1.0 还是 MySpeed，影响纹理采样步长。

所有 Set 调用按执行顺序排列，确保依赖关系正确。
